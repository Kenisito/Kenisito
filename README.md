## 🧠 Lo que me interesa resolver

Me interesa construir herramientas que puedan analizar un repositorio y responder preguntas como:

- ¿Qué tecnologías utiliza?
- ¿Qué workflows existen?
- ¿Cómo se relacionan los GitHub Actions?
- ¿Qué servicios dependen entre sí?
- ¿Qué componentes forman parte de la arquitectura?
- ¿Qué riesgos de seguridad existen?
- ¿Cómo está construido el flujo de CI/CD?
